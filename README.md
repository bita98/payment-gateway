# PayGate — Payment Gateway

A modern and responsive payment gateway interface built as a front-end portfolio project.

PayGate simulates a real-world online payment experience with an interactive payment form, client-side validation, security-focused UI elements, and a successful transaction state.

## ✨ Features

- Responsive payment gateway interface
- Modern and clean UI
- Fully responsive layout
- Payment amount formatting
- 16-digit card number validation
- Expiry date formatting
- CVV2 input
- Cardholder name input
- Random security captcha
- Captcha refresh functionality
- Payment countdown timer
- Loading state during payment processing
- Successful payment state
- Generated transaction tracking code
- Persian RTL interface
- Mobile-friendly design

## 🛠️ Technologies

- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- Vite-free Tailwind CLI setup

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/bita98/payment-gateway.git
```

Navigate to the project:

```bash
cd payment-gateway
```

Install dependencies:

```bash
npm install
```

Start Tailwind CSS in development mode:

```bash
npm run dev
```

Then open `index.html` in your browser.

## 💳 Payment Flow

The project simulates the following payment process:

1. Enter the payment amount
2. Enter a 16-digit card number
3. Enter the card expiry date
4. Enter CVV2
5. Enter the cardholder name
6. Enter the security captcha
7. Submit the payment
8. Display a processing state
9. Display the successful payment result

This is a front-end simulation and does not process real financial transactions.
